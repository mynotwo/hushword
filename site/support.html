Hushword support.

Hushword v{{VERSION}} supports Apple Silicon Macs running macOS 13.3 or later. Intel Macs are not supported.

Hushword cannot hear you

Open System Settings → Privacy & Security → Microphone and enable Hushword. Then quit and reopen the app.

The transcript is copied but not inserted

Enable Hushword under Privacy & Security → Accessibility. Return to the target text field before starting the next dictation.

The local model failed to download

Open Hushword Settings and select Retry. The 574 MB model requires an internet connection only for the initial verified download.

Hold Fn does nothing

Normal dictation does not require an Agent. Optional rewrite requires Claude, Codex, or Coco to be installed and signed in. Check the Agent status in Hushword Settings.
